# Biblioteca CRUD - Prueba Técnica JR Developer

Estructura inicial:
- backend/: API (Spring Boot)
- frontend/: App (Angular)
  
Ramas:

-main: Contiene la versión estable del proyecto. 
       Solo se hacen merges desde develop o ramas de hotfix.

-develop: Rama principal de desarrollo.
          Aquí se integran todas las funcionalidades antes de pasarlas a main.

feature/*: Ramas específicas para cada nueva funcionalidad o tarea.

Cada carpeta tiene su archivo explicando como debe de instalarse y ejecutarse. Muchas gracias.
