Biblioteca Frontend – Prueba Técnica

Airton Jairo Sampayo Solano.

Aplicación web desarrollada con Angular y PrimeNG para la gestión de una biblioteca.
Permite interactuar con la API del backend para administrar libros, miembros y préstamos.
La interfaz es responsiva y moderna, con validaciones en formularios y mensajes de feedback.

Ejecución del proyecto
Requisitos previos

Tener instalado Node.js (versión 18 o superior recomendada).

Tener instalado NPM (viene con Node.js).

Backend corriendo en http://localhost:8080 para que la app pueda consumir la API.

Pasos para ejecutar:
# Clonar el repositorio
git clone https://github.com/Baltho23/Biblioteca.git

# Entrar a la carpeta del frontend
cd frontend

# Instalar dependencias
npm install

# Iniciar la aplicación
ng serve
